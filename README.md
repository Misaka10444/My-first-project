\# 豆瓣Top250爬虫



一个用Python写的豆瓣电影Top250数据采集练习项目。



\## 功能

\- 爬取豆瓣Top250电影信息

\- 提取电影名、评分、评价人数

\- 结果打印在命令行



\## 使用的库

\- requests

\- BeautifulSoup4



\## 运行方法

1\. 安装依赖：pip install requests beautifulsoup4

2\. 运行程序：python douban\_top250.py
